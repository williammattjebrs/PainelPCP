# Painel PCP — prévia visual

Protótipo estático da interface para revisão de layout e navegação. Usa apenas dados demonstrativos fictícios: não autentica usuários, não chama a API, não acessa banco e não grava alterações.

Abra `index.html` em um servidor estático para visualizar. A tela representa a direção visual inicial; os fluxos administrativos e de consulta ainda serão conectados à API de teste após a revisão visual.

A aplicação Streamlit e o banco histórico não são alterados por esta prévia.
